# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**.

This project helped me practice DOM manipulation, event handling, game logic, and JavaScript functions.

## ✨ Features

* 🎮 Two-player Tic-Tac-Toe game
* ❌ Player 1 plays as **X**
* ⭕ Player 2 plays as **O**
* 🏆 Automatically detects the winner
* 🎉 Displays a congratulations message when a player wins
* 🔒 Disables boxes after they are selected
* 🔄 **New Game** button to start a fresh game
* ♻️ **Reset Game** button
* 🎨 Winner message styling using JavaScript
* 🖥️ Simple and responsive interface

## 🎯 How the Game Works

1. Player 1 starts with **X**.
2. Players take turns selecting an empty box.
3. The game checks the selected boxes against predefined winning patterns.
4. When three matching symbols are found, the winner is displayed.
5. The board is disabled after a winner is found.
6. Clicking **New Game** clears the board and starts a new round.
